# ⚡ Missão Tabuada (Volume 1: Do 1 ao 10)

> Material pedagógico e interativo para domínio completo da multiplicação infantil através do método dos micro-passos e repetição espaçada.

---

## 🎯 Conteúdo do Projeto

- **`index.html`**: Aplicação Web Interativa com cronômetro em tempo real, validação sonora de respostas e efeitos visuais com confetes.
- **`Missao_Tabuada_Volume_1.pdf`**: Livro completo em PDF com 43 páginas em formato A4, com 944 campos preenchíveis digitais (AcroForms) e pronto para impressão.
- **`assets/`**: Mascotes, escudos e elementos gráficos em alta resolução.
